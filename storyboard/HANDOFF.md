## 6. Git 纪律（本项目补充）

> 通用收尾流水线（commit → tag → 显式推送 → 落地 main → `ls-remote` 自证）见 `~/.dsh/AGENTS.md` §2。
> 本节只写项目特有的：分支命名、tag 命名、远程结构、以及**不能再犯的具体错误**。

- 分支命名：`card/<NN>-<slug>`（例 `card/01-periodic-table-24s`）；tag 命名：`v<N>-card<NN>-<slug>`（例 `v1-card01-periodic-table`），tag 消息须含**成片 md5 + 行数/帧数**，且**指向实现提交**。
- 远程：**当前无 remote（实测 `git remote -v` 为空）**。收尾时若仍无远程，**不得**伪称已推送 —— 按 `~/.dsh/AGENTS.md` §2 停下来问人。
- 本项目踩过的坑：
  1. **默认抓 5173 = 旧项目**：流水线 URL 默认值写死在 `render-frames.js`/`make-video.js`，务必显式传 `--url`。
  2. **`--limit` 冒烟不补帧且会清目录**：`render-frames.js` 导出前会删掉输出目录里的 `frame_*.png`；冒烟务必用 `--frames video/frames-smoke`，否则会毁掉已渲染的全量帧。
  3. **`--out` 默认名不是我们要的**：`make-video.js --out` 默认 `video/out/video.mp4`，成片名必须显式给。
  4. **`verify/visual/baseline/` 是模板继承来的旧项目图库**：本项目页面与它无关，禁止跑 `visual.js shoot` 覆盖；卡 01 唯一门禁是 `verify/card-01/gate.js`，不跑 `run-all.js`。
